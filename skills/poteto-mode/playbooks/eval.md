# Eval

Test how a skill or prompt change affects agent behavior — blinded when possible.

1. Define **success metric** and tasks **before** looking at the new variant's outputs.
2. Run baseline and candidate on the same tasks.
3. Score against the metric, not vibes.
4. Report before/after with the metric and failure modes.
5. Do not merge a skill change on anecdote alone.
6. **Reply:** metric, task set, scores, decision.
