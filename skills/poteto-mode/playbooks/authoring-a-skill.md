# Authoring a skill

Write or edit a `SKILL.md`.

1. **name**: kebab-case, matches directory name.
2. **description**: what + when; trigger phrases; plain YAML scalar; no colon-space that forces bad quoting; under 1024 chars.
3. **Body**: imperative, short. Only what the model does not already know.
4. Progressive disclosure: keep SKILL.md lean; put long detail in `references/`.
5. Run through **unslop**.
6. If the host has a skill linter or create-skill flow, use it.
7. **Reply:** path, triggers, what the skill does in one paragraph.
