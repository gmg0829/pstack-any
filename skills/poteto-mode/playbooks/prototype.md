# Prototype

Throwaway sketch to settle a design or behavioral fork cheaply.

1. State the **decision** the prototype must settle and what evidence counts as settled.
2. Build the **smallest observable sketch** (not production polish).
3. Run it. Record what you saw.
4. **Decide** from the evidence. Discard or promote deliberately.
5. Do not silently keep prototype code as production without a conscious promote step.
6. **Reply:** question, sketch, observation, decision.
