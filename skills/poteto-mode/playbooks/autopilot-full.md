# Autopilot full

Independent PRs to merged: one owner per PR, root verdict each round.

1. Start from code-ready heads.
2. Assign ownership per PR (logical owner; spawn if harness allows).
3. Each round: per-PR progress → root verification → merge only when verified.
4. Do not enable auto-merge on unverified stacks.
5. **Reply:** per-PR state, merges, blocked items.
