# Refactoring

Behavior-preserving structural change.

1. **Capture current behavior** with tests or a manual oracle on the real surface.
2. Change **structure only** — no feature creep.
3. Prefer **subtract-before-you-add** and **minimize-reader-load**.
4. **Re-verify** identical observable behavior.
5. Small commits that each leave the tree green when practical.
6. **Reply:** what moved, what stayed behaviorally identical, how verified.
