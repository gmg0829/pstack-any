# Hillclimb

Sustained scientific improvement of one metric against a target.

1. Name the **metric**, the **target**, and the **measurement method**.
2. Loop:
   - Form a hypothesis
   - Apply the smallest change that tests it
   - Measure before/after the same way
   - Keep only accepted wins
   - Prefer **one commit per accepted win**
3. Stop at target, diminishing returns, or operator interrupt.
4. Persist a short trail of hypotheses and outcomes (**show-me-your-work** if long).
5. **Reply:** metric path, wins kept, rejects, current number vs target.
