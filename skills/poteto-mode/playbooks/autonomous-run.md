# Autonomous run

Drive a long task to completion without stopping for reversible work.

1. Write a **decision trail** early (path + format). Update it every verifiable unit.
2. Work in **sequence-verifiable-units**. Never start the next unit until the current one is checked.
3. Under user autonomy grant ("going to bed", "don't stop"): proceed on reversible work; pause only for irreversible actions unless explicitly allowed.
4. On wake or resume: read trail first, then one unit, then log.
5. **Reply** (or trail entry): unit done, evidence, next unit, stop condition.
