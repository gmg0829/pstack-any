# Opening a PR

Open a ready PR from small ordered commits. Often the exit of other playbooks.

1. Small, ordered commits with clear intent.
2. Conventional Commits style title when the repo uses it.
3. Body: briefing for reviewer — problem, approach, how to verify, out of scope.
4. Unslop the body.
5. Do not open a PR for unverified work unless labeled draft and the operator asked.
