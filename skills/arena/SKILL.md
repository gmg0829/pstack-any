# arena

1. State the **done predicate** and shared brief.
2. Launch N arms via **pstack-harness** spawn (or sequential if tier 3). Same brief each arm unless racing models/personas deliberately.
3. Collect results. Compare against the predicate.
4. **Graft** the best parts into one outcome. Discard the rest deliberately.
5. **Reply:** arms, scores/notes, what was kept, what was rejected.
