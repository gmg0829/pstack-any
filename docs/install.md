# Install

## skills CLI

```bash
npx skills add gmg0829/pstack-any
```

Select skills and target agents when prompted.

## Manual

```bash
git clone https://github.com/gmg0829/pstack-any.git
cp -R pstack-any/skills/* ~/.claude/skills/
```
