# technical-writing

1. Name the **audience** and the **job** of the doc (tutorial / how-to / reference / explanation when useful).
2. Lead with the action or decision the reader needs.
3. Short paragraphs. Concrete verbs. Unslop.
4. PR bodies: problem, approach, how to verify, out of scope.
5. Commit subjects: imperative, specific; body only when needed.
