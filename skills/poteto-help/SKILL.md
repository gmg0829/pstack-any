# poteto-help

1. Clarify the goal in one sentence (ask if needed).
2. Map to a **playbook** or **specialist** from poteto-mode.
3. Hand back a **copy-paste prompt** that invokes it.
4. Link the skill/playbook name. Do not run the whole task unless asked.
