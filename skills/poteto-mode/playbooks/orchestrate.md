# Orchestrate

Standing multi-day project: many stacked PRs, fleets of workers, one coordinator chat.

1. Open a worklist of phases with verifiable exits.
2. Partition work. Spawn workers via **pstack-harness** (or sequential if tier 3).
3. Aggregate reports. Root chat owns verdicts — do not rubber-stamp child summaries.
4. Land only contiguous verified runs (**shipping** norms).
5. Keep a durable trail for session-pickup.
6. **Reply:** phase status, open risks, next verifiable exit.
