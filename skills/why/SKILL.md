# why

1. Gather design evidence: commits, issues, docs, ADRs, chat notes if available.
2. Separate **recorded intent** from **inference**. Label each claim.
3. If evidence is thin, say so. Do not invent a founding myth.
4. For "are we sure?" include real judgment and whether the premise should be re-tested (**attack-the-premise**).
5. Cite sources. Unslop the reply.
