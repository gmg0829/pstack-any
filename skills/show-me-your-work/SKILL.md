# show-me-your-work

1. Choose a trail path (e.g. `decisions.tsv` or `decisions.md`) the operator can commit.
2. Each row/entry: time, decision, why, evidence, rejected alternatives.
3. Update at every verifiable unit on long runs.
4. On resume, read the trail before acting.
